Code review and security audit

Report opened: at

This page was built by merging seven earlier files into one. This is what the review of that merge found.

Problems found and fixed

  • Four outside resources were removed (Tailwind, Font Awesome, Google Fonts and a confetti library). The page now loads nothing from the internet while it runs.
  • Text typed by a visitor was being inserted into the page as HTML, which could run injected code. It is now always inserted as plain text.
  • A page-wide rule that blocked text selection stopped typing in some Safari browsers. It was removed.
  • One icon had a corrupted drawing path. It was repaired.
  • The calendar file saved 7 pm as 7 pm UTC and lacked required fields. It now uses the visitor’s own time zone.
  • Two WhatsApp links held fixed text, one with a wrong emoji. Every link is now built from the real plan.
  • Sample answers and pre-selected choices were removed, so the plan only holds what the visitor chose.
  • Buttons that only showed a message now work: Save image, Start over, Privacy Policy and Terms of Service.
  • The old audit button claimed the page was “verified and encrypted”. Nothing is encrypted, so that claim was removed.
  • Copying has a backup method. Dialogs hold keyboard focus, close with Escape and give focus back.
  • Animation stops when the tab is hidden and when reduced motion is requested. A “Pause animations” switch was added for anyone who finds movement distracting.

Known limits

  • Automatic tests ran in one Chromium browser. Safari, Firefox and real phones have not been tried.
  • A single file cannot install as an app or keep an offline copy by itself. It does work offline once it is open.
  • WhatsApp and Instagram open in their own apps or sites. This page cannot tell whether a message was sent.
